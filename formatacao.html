🌐 Redes, Diagnóstico & Formatação

Procedimentos essenciais para resolução de problemas de conectividade de rede e roteiro padronizado de formatação do sistema.

📡 Resolução de Problemas de Rede & DNS

1. Flush DNS & Reset da Pilha TCP/IP

Limpa a tabela de resolução de nomes DNS corrompida e restaura as configurações padrão dos adaptadores de rede Winsock e IP.

ipconfig /flushdns
ipconfig /release
ipconfig /renew
netsh winsock reset
netsh int ip reset

2. Entendendo e Usando o Comando PING

O PING envia pacotes ICMP para testar conectividade e latência com um destino na rede.

# Testar se a placa de rede local está funcionando (Loopback)
ping 127.0.0.1

# Testar se o computador alcança o Roteador (Gateway Padrão)
ping 192.168.1.1

# Testar se a conexão de internet externa e o DNS público do Google funcionam
ping 8.8.8.8

# PING contínuo para verificar perda de pacotes ao longo do tempo
ping google.com -t

💾 Guia Passo a Passo: Formatação Limpa do Windows

01

Criar Pendrive Bootável

Baixe a ferramenta oficial Media Creation Tool da Microsoft ou utilize o Rufus junto de uma imagem ISO do Windows 11/10.

02

Backup de Dados Pessoais

Copie pastas importantes (Documentos, Fotos, Downloads) para um HD Externo ou Nuvem. A formatação apagará todos os dados na partição C:.

03

Boot pela BIOS/UEFI

Ligue o computador pressionando a tecla de Boot (geralmente F12, F11, F8 ou Delete) e selecione a inicialização a partir do Pendrive SanDisk/Kingston.

04

Particionamento & Instalação

Na tela de instalação, selecione "Personalizada", exclua as partições antigas do disco do sistema, selecione o "Espaço Não Alocado" e avance.
