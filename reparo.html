Início Dicas Rápidas Scripts Windows Redes & Formatação Programas Essenciais

⚡ Repositório de Scripts de Reparo (Windows)

Comandos nativos para reparo de arquivos do sistema operacional, verificação de disco e atualização em massa de programas.

⚠️ Atenção Técnica: Todos estes comandos devem ser executados no Prompt de Comando (CMD) ou PowerShell como Administrador.

1. SFC /SCANNOW (System File Checker)

Verifica a integridade de todos os arquivos protegidos do Windows e substitui versões corrompidas por cópias de backup mantidas em cache no sistema.

sfc /scannow

2. DISM (Deployment Image Servicing and Management)

Repara a imagem de componente do Windows que o SFC utiliza para recuperar arquivos. Executado quando o SFC encontra erros que não consegue corrigir sozinho.

DISM /Online /Cleanup-Image /RestoreHealth

3. CHKDSK (Check Disk com Reparo de Setores)

Examina a estrutura do sistema de arquivos na unidade C:, corrige erros lógicos de disco e localiza setores defeituosos (bad sectors) para marcar como inutilizáveis.

chkdsk C: /f /r

4. WINGET UPGRADE (Atualização de Todos os Programas)

Utiliza o gerenciador de pacotes oficial do Windows (Winget) para verificar e atualizar automaticamente TODOS os softwares instalados no computador para a versão mais recente.

winget upgrade --all --include-unknown

5. Limpeza de Caches de Atualização (Reset do Windows Update)

Para os serviços do Windows Update, apaga o cache de arquivos temporários de download e reinicia os serviços. Resolve 90% dos erros de travamento na instalação de atualizações.

net stop wuauserv
